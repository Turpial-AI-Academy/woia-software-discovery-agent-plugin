# AGENTS.md

This is a thin WOIA provider repository.

- Preserve the `discovery` capability/skill semantics.
- Runtime tools/scripts/templates specific to this capability belong inside the portable plugin.
- Generic Factory/certification tooling belongs in `woia-ecosystem`, not here.
- Consumers install/update released artifacts; they do not edit canonical source.
- Only authorized WOIA maintainers/developers modify or publish this repository.
